# 开发体验记录（未发布）

本轮仅提交源码并检查，不生成 macOS / Windows 安装包、不触发安装包构建工作流、不提升发布版本号。

## 本轮完成

- 阅读正文左右默认留白 24 点；小窗口至少 18 点，上下增加正文与控件的间隔，分页按实际可用正文区域重新测量。
- 分显示器保存阅读区的相对位置和逻辑宽高。切换、插拔或改变工作区后恢复对应布局，并限制在可见工作区内。屏幕使用系统名称识别，同名屏幕可能共用布局。
- 设置页录入五组全局快捷键：隐藏/继续、返回书架、调整区域、上一页、下一页。拒绝重复键和无修饰键；注册失败会回退旧绑定，并显示未启用项。阅读窗口内 Esc 暂停隐藏，Ctrl/Cmd+F 打开搜索。
- 关于与诊断页提供版本、开发预览标记、代码版本、构建时间、平台、快捷键状态、已保存布局；可打开日志目录，或选择位置导出本地诊断 ZIP。导出仅含环境摘要和限定名称的诊断日志，不含书架或正文，不上传。
- 隐藏后重新阅读时短暂标记当前页第一行；翻页或隐藏立即取消提示。减少动态效果的系统设置下不显示提示。
- TXT 识别常见中文章节和英文 Chapter 标题；EPUB 3 读取原生 nav，EPUB 2 读取 NCX，支持文件内锚点、层级及 UTF-16 位置，无原生有效目录时回退 spine 标题。显示当前章节及章节内进度。
- 每本书独立书签，可命名、跳转、删除；重复保存同一位置更新名称。目录、书签和搜索跳转保留最多 50 次原位置，支持“返回原处”。窗口缩放不改变原文锚点；切书后清空跳转历史。
- 书内精确文本搜索优先在 Worker 中运行，不支持 Worker 的桌面 WebView 回退为异步分批搜索，展示上下文及关键词，按每批 100 条加载，忽略旧查询/旧书籍结果；点击结果定位并保存阅读进度。

## 体验方式

先退出已安装的旧版隐阅，避免两个进程争用全局快捷键或同时写书架，再在项目目录执行：

```sh
npm ci
npm run desktop
```

新数据仍保存在本机书架中，旧书架自动提供新增字段默认值。开发体验期间不要与旧版同时运行。

阅读窗口“工具”打开目录、书签和搜索。打开工具时切换到持续可见预览；关闭后点击“开始阅读”重新启用悬停，避免操作工具时自动隐藏。

## 检查范围

本地检查：前端类型与生产资源构建、分页/搜索/跳转历史测试、Rust 编码/EPUB/原生窗口保护/目录锚点/旧数据兼容/快捷键校验/书签定位/诊断导出测试。浏览器独立测试页验证留白、目录与搜索跳转、返回原处、书签、快捷键录入和关于页。

Windows 使用独立的 `Check source without packaging` 工作流，仅构建前端资源和运行单元测试，不生成安装包。

真实多屏插拔、系统级快捷键占用回退、原生保存对话框及长期悬停表现仍需开发版实机体验；本轮没有发布安装包验收。

## 设置页样式整理

移除侧栏底部的快捷键说明；快捷键配置继续保留在阅读设置中。设置页统一标签/控件对齐、分组留白、输入框高度、按钮与状态文字间距，背景浓度显示百分比。修复快捷键输入框拦截 Tab 的问题，支持正常移至下个控件。视觉检查覆盖默认尺寸及应用最小宽度 760 点，页面及各设置行无横向溢出。本轮仍不打包。

## 后台背景

书架、阅读设置和关于页采用选定的淡绿色山水背景，侧栏、按钮和设置卡片使用配套的绿色与半透明米白色。背景随窗口等比铺满，仅应用于后台，阅读窗口继续使用原有主题与透明隐藏方式。图片作为本地资源随应用加载，无需联网。
