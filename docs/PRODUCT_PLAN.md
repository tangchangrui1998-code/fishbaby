# 悬浮文字阅读器：第一版产品方案

状态：开发基线（2026-10-28）  
目标平台：macOS；Windows 提供独立分支与 GitHub Actions 构建配置，待 Windows 环境验证
暂定名称：隐阅

## 1. 产品目标

在桌面上放置一个可移动、可调整大小的阅读区域。鼠标进入该区域后显示当前文字；鼠标移出后，区域内所有内容与背景完全透明，且不阻挡下方应用的鼠标操作。用户能够用短暂的空闲时间继续阅读，并准确从上次位置接着看。

第一版的成功标准是：出现和消失足够稳定，隐藏时不影响正常工作，重新打开后阅读位置正确。

## 2. 核心使用流程

1. 用户从菜单栏打开书架，导入一部或多部本地 TXT / EPUB 文件，自动读取支持的编码和章节正文。
2. 用户在书架中点击“阅读/继续阅读”，书架最小化，显示可移动、持续可见的阅读窗口。窗口提供“开始阅读”和“返回书架”。
3. 用户在阅读窗口点击“开始阅读”后启用悬停模式。鼠标在区域外时看不到文字、背景、边框或占位标记；点击“返回书架”恢复后台，点击“暂停阅读”恢复持续可见状态。
4. 鼠标进入区域并停留约 150 毫秒后，显示当前位置的文字；滚轮可向前或向后翻页。
5. 鼠标离开后，区域在 150 毫秒内完全透明并恢复鼠标穿透。
6. 用户下次启动时，应用恢复书架、上次阅读的书籍、该书的阅读位置、区域位置和样式。切换书籍时，每本书从自己的进度继续。

## 3. 交互状态

| 状态 | 画面 | 鼠标行为 | 进入方式 |
| --- | --- | --- | --- |
| 设置 | 显示边框、拖拽柄和设置入口 | 可拖动、缩放、操作控件 | 菜单栏“调整阅读区域” |
| 待开始 | 阅读窗口持续可见，可预览、移动、切换主题或返回书架 | 鼠标移出不会隐藏 | 书架“阅读/继续阅读”，或阅读窗口“暂停阅读” |
| 隐藏 | 全透明，无可见占位 | 鼠标操作传递给下方窗口 | 开启悬停阅读或鼠标离开 |
| 阅读 | 显示文字；背景默认透明，可选半透明底色 | 滚轮翻页，停留期间可操作 | 鼠标进入区域且达到悬停时长 |
| 暂停 | 不响应悬停，阅读区域隐藏 | 不影响下方窗口 | 菜单栏或快捷键暂停 |
| 书架 | 显示书籍列表、阅读进度和导入入口 | 可选书、导入、移出书架 | 菜单栏“打开书架” |

状态切换原则：隐藏状态必须同时满足“视觉透明”和“鼠标穿透”。区域隐藏时不能只依赖窗口自身的 `mouseenter` 事件唤醒；由桌面侧检测指针是否进入保存的区域，再切换到阅读状态。阅读状态下，指针离开区域就恢复隐藏状态。悬停时长用于减少鼠标路过造成的误触发，后续可在设置中调整。

## 4. 第一版范围

### 必须完成

- 菜单栏入口：打开书架、导入 TXT、调整阅读区域、暂停/继续、退出。
- 阅读区域：置顶、无系统边框、可拖动及缩放、跨启动保存位置；默认尺寸 420 × 160 逻辑像素。
- 悬停显示与离开隐藏；隐藏时完全透明且鼠标穿透。
- TXT 阅读：支持 UTF-8、GB18030/GBK/GB2312、带 BOM 的 UTF-16 LE/BE 导入，按显示区域排版、滚轮翻页、按书自动保存阅读位置。
- EPUB 阅读：支持未加密的 EPUB 2/3，按 OPF spine 顺序提取正文并保留标题和段落；使用统一阅读样式与原文进度。
- 书架：一次导入多本 TXT / EPUB；展示书名、格式、阅读百分比和最近阅读时间；按最近阅读排序；选择一本继续阅读；将书移出书架。
- 阅读主题：浅色、深色，可从书架设置和阅读窗口顶部切换并保存。
- 字体设置：字号、文字颜色、行距、背景透明度；提供“单行”和“段落”两种布局。
- 全局快捷键：切换暂停/继续，以及打开区域设置。快捷键可修改，冲突时提示。
- 本地保存书架、当前书籍、每本书的阅读位置和偏好设置；文件失效时提示移出后重新导入。

### 暂缓

PDF、EPUB 图片与原版排版、章节目录跳转、DRM 加密书、云同步、封面抓取、标签与书架分组、全文搜索、账号、自动滚动、划词翻译、跨平台发布，以及任何对系统监控或截图行为的处理。

### 书架交互规则

- 首次启动显示空书架和导入入口；没有书籍时不能进入悬停阅读。
- TXT 导入时以文件名作为书名；EPUB 优先使用书内标题，缺失时使用文件名。相同文件路径重复导入不创建重复项。
- 书架默认按最近阅读排序；当前书籍标记为“正在阅读”，点击其他书籍立即切换并恢复其独立进度。
- 进度在翻页后保存，切书、暂停和退出时再次保存。进度锚点基于原文位置，不依赖页面编号，因此改变字号和区域大小后仍能从相近文字继续。
- “移出书架”只删除应用内的书籍记录和该书进度，不删除磁盘上的 TXT 文件；执行前说明这一点并确认。
- 原文件被移动或删除时，书籍仍留在书架并标记“文件不可用”；用户可将其移出书架后重新导入。

## 5. 关键细节和异常情况

- **误触发：** 鼠标快速划过阅读区不显示；达到悬停时长才显示。
- **正常点击：** 隐藏时点击应落到下方应用。阅读状态会接管阅读区内的输入，因此提供快捷键快速暂停。
- **找不到区域：** 菜单栏始终可进入设置模式，显示区域边框，并提供“重置到当前屏幕中央”。
- **多显示器：** 保存区域所属屏幕和坐标；屏幕断开或分辨率变化后，将区域移回可见范围。
- **无书籍：** 保持设置模式，提示导入文件，不进入空白的隐形状态。
- **同名书籍：** 以文件位置识别重复导入；同名但不同路径的文件可以同时存在，并在书架里显示路径辅助区分。
- **原文变化：** 若文件内容变化，优先尝试恢复原文锚点；无法匹配时按原阅读百分比定位，并提示用户确认进度。
- **文本编码：** 优先遵循 BOM；无 BOM 时优先 UTF-8，失败后按 GB18030 严格解码，兼容 GBK/GB2312。UTF-16 LE/BE 需带 BOM；不支持或损坏的编码提示另存为 UTF-8，不用替换字符吞掉解码错误，不改写原文件。无 BOM 编码存在歧义，不能保证识别所有编码（例如 Big5）。
- **EPUB 异常：** 文件损坏、缺失正文、加密或纯图片书给出明确提示；字体混淆不阻止读取正文。单文件和解压读取的正文及目录各限制 50 MB，不执行书内脚本，不加载远程资源。
- **性能：** 隐藏时仅做轻量指针区域判断；不持续重排全文；页面切换时才更新可见文本。

## 6. 技术方向

采用 Tauri 2、前端 Web UI 和少量 macOS 原生能力。界面负责书架、排版、设置和阅读交互；桌面侧负责窗口置顶、透明/鼠标穿透、全局快捷键、指针位置与阅读区域的判定、本地持久化。先做单窗口原型验证悬停切换，再加入书架与文件读取。

本地数据至少包含：书籍 ID、书名、文件路径、原文指纹、每本书的阅读锚点、最近阅读时间、当前书籍 ID，以及阅读区域与样式设置。书籍记录与原始 TXT 分开保存，移出书架时不得修改原文件。

实现前需要验证三件事：

1. 隐藏状态下是否能稳定检测鼠标进入区域，同时让点击传递给下方应用。
2. 阅读状态与隐藏状态切换时是否出现闪烁、残影或意外抢焦点。
3. 不同缩放比例及多显示器下，指针坐标与窗口区域是否一致。

参考：[Tauri 窗口 API](https://tauri.app/reference/javascript/api/namespacewindow/)；[Tauri 窗口权限](https://v2.tauri.app/reference/acl/core-permissions/)。

## 7. 验收标准

- 在 macOS 上，鼠标离开阅读区后 150 毫秒内，区域完全不可见；点击和滚动能作用于下方应用。
- 鼠标进入阅读区并停留约 150 毫秒后，文字稳定出现；快速划过不出现。
- 连续重复进入/离开 30 次，无卡在显示态、闪烁或无法唤醒的情况。
- 导入一份至少 1 MB 的 UTF-8 TXT，翻页流畅；退出重启后回到相同阅读位置。
- 导入 GBK、包含四字节字符的 GB18030、带 BOM 的 UTF-16 LE/BE，正文与原文一致；损坏的编码显示错误，空文件提示无文字。
- 导入 EPUB 2/3，正文顺序遵循 spine 而不是文件名；标题、段落和特殊字符正确，切书和重启后沿用每本书的阅读位置；损坏、加密和纯图片书不会导入为空白书籍。
- 导入至少 3 本 TXT，分别阅读到不同位置；切书和重启后均能恢复各自进度，改变字号后进度仍对应相近原文。
- 重复导入同一路径不会产生重复书籍；移出书架后原始 TXT 仍在磁盘上；原文件丢失时提示移出后重新导入。
- 调整区域后重启，位置、尺寸、样式均恢复；断开外接显示器后区域仍可找回。
- 菜单栏和快捷键始终能暂停悬停阅读、进入设置模式或退出应用。

## 8. 开发顺序

1. **交互原型：** 透明置顶窗口、区域定位、悬停显示、离开隐藏、鼠标穿透、设置模式。
2. **书架与阅读：** 多书导入、书架列表、按书保存进度、切书、排版、翻页。
3. **可用性：** 菜单栏、快捷键、样式设置、多显示器恢复、文件失效处理和异常提示。
4. **验证：** 按第 7 节逐项进行真实桌面测试并修复问题。

第一阶段的通过条件是：即使用一段固定样本文字，也能可靠完成“隐藏 → 悬停显示 → 离开隐藏”，且隐藏时不影响桌面操作。

## 9. 当前开发状态（2026-10-28）

已实现首个 macOS 开发版本：书架、批量 TXT 导入、每本书的独立进度、切书、移出、样式设置、悬浮窗口与悬停检测、菜单栏和固定快捷键。应用可以构建为本地 `.app`，书架和阅读窗口已完成启动界面检查。

自动检查覆盖翻页位置、Unicode 边界、TXT 编码处理、独立进度序列化。完整桌面验收仍按第 7 节执行；快捷键自定义尚待补齐。开发构建尚未签名和公证。

当前阅读流程：书架“阅读/继续阅读”最小化后台并打开持续可见的阅读窗口；仅点击阅读窗口“开始阅读”才进入悬停模式。窗口提供“返回书架”和“暂停阅读”。深浅主题及阅读进度继续保留。回归检查覆盖待开始状态、显式开始后移出隐藏/重新进入唤醒、返回书架与重新选书。

阅读期间重新激活应用时，保留阅读窗口与当前模式，不自动恢复后台；返回后台使用阅读窗口“返回书架”、菜单栏入口或打开书架快捷键。后台已最小化时不重复触发最小化。

窗口悬停判断：可见时使用阅读区指针事件，点击开始时明确记录鼠标位于阅读区；隐藏后以全局鼠标位置检测再次进入。全局鼠标和窗口边界分别按所属显示器缩放比例转换到逻辑坐标后比较。回归覆盖混合缩放、点击瞬间全局坐标尚未更新，以及激活事件不恢复后台。桌面实测确认“开始阅读 → 暂停阅读”保持阅读窗口，“返回书架”恢复后台。

本轮修复：主题及其他样式更新默认保留阅读窗口的实时宽高，只有明确修改尺寸输入时才调用窗口缩放；拖动缩放产生的尺寸变化同步保存。悬停移出时保留透明原生窗口，仅隐藏内容并开启鼠标穿透，避免首次移出时 macOS 恢复后台；暂停或返回书架才隐藏原生阅读窗口。回归检查覆盖样式不重置尺寸，以及首次移出后原生窗口保持存在、阅读模式保持悬停。

书架界面改版：只保留阅读与移出操作，取消改名和重新定位；书架与阅读设置分开，移除装饰符号与宣传文案。阅读区新增整本书进度滚动条，支持点击、拖动和键盘定位；滚轮翻页和原文进度锚点保持一致。视觉参考：[Koodo Reader](https://github.com/koodo-reader/koodo-reader) 的资料库布局与 [Readwise Reader](https://readwise.io/read) 的阅读界面，采用独立实现的纯色书封、系统字体和分组设置。

本轮验证：书架及阅读设置页已完成原生窗口截图审阅；独立测试页验证滚动条拖动定位、键盘末页跳转和阅读位置保存。自动检查包含 Unicode 边界、首末页映射、短文滚动条，以及既有悬停与主题尺寸回归。

分发与分支：`main` 保留公共基线，`mac` 和 `windows` 分别用于平台开发与打包。macOS 生成 arm64 Release `.app` 与 `.dmg`，使用 ad-hoc 签名；Windows 提供手动 GitHub Actions 构建 NSIS x64 安装包及 SHA-256 校验文件，本轮不触发 Windows 构建。安装包不进入 Git 历史。
